# ⚽ Soccer Striker AI

Assistente estatístico inteligente para jogos de pênalti. O bot analisa o comportamento do goleiro e sugere a melhor direção para chutar.

## 🎮 Como funciona

O Soccer Striker AI é um assistente que aprende com o histórico de defesas do goleiro. Você registra onde chutou e se fez gol ou não, e a IA calcula probabilidades para sugerir o melhor canto.

## ✨ Funcionalidades

- 📊 Análise estatística em tempo real
- 🎯 Sugestões baseadas em probabilidade
- 📈 Gráficos de tendência
- 💾 Salvamento automático em CSV
- 🔄 Múltiplas janelas de análise
- 🧠 Detecção de padrões (repetição/alternância)
- ⭐ Nível de confiança nas sugestões
